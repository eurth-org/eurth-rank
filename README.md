# Rank

> A friendly note: Rank is part of Eurth's advent calendar, and its door opens on 20 December 2026. The code is public, the site isn't yet. Please don't spoil the surprise before the door opens.

Rank builds a fictional nation's military ranks and draws their insignia: shoulder boards, sleeve stripes and chevrons, collar pips, for an army, a navy, an air force and any branch you add. It is one of the free worldbuilding tools by [Eurth](https://eurth.org), a worldbuilding and roleplay community since 2004, and will live at rank.eurth.org.

Nothing is built yet. The plan, and exactly where work stands, is in [roadmap.md](roadmap.md).
